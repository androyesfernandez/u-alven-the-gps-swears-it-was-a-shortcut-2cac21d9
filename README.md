# The GPS Swears It Was a Shortcut

A tiny TypeScript program that delivers the GPS's one-line excuse for driving
straight into a lake: the map insists the lake is a shortcut, the satellite
outranks your panicking eyes, and congratulations — we're baptising the car
at the lakeside wedding.

Run `node main.ts` and it writes the line, exactly one line with no trailing
newline, to `/output/entry.txt`.
